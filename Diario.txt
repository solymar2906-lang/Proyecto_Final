se hablo de Numpy una librería de Python.
Qué es NumPy?: Es base de la ciencia de datos en Python. Usa arreglos (ndarray) que guardan datos del mismo tipo y permiten hacer operaciones rápid
as sin usar ciclos for (vectorización).  

Se crean arreglos con np.array, ceros o datos aleatorios. Su .shape nos dice filas (observaciones) y columnas (variables).
  
Se accede con [fila, columna]. Ojo: los cortes (:) crean vistas que modifican el original si no usamos .copy().  

NumPy ajusta formas distintas automáticamente para operar. Usamos máscaras booleanas (ej. notas >= 3) para filtrar datos fácilmente.  

Vimos .reshape() para cambiar formas, manejo de nan con funciones como np.nanmean() para no dañar los cálculos, y un reto práctico al final.

Se habló de la librería pandas .
Qué es pandas?: Es la librería de Python que se encarga de organizar, cargar, limpiar y transformar la información en formato de tabla antes de analizarla. 
 
Estructura:El DataFrame es la tabla completa con filas y columnas etiquetadas, y una Series es una sola columna de esa tabla.  

Al cargar un archivo, siempre revisamos con df.shape, df.head(), df.info() y df.describe() para entender filas, tipos de datos y nulos.  

Se usa df.loc[] por etiqueta y df.iloc[] por posición. Para filtrar filas con condiciones se usan máscaras booleanas con la misma lógica de NumPy.  

Podemos detectar nulos con df.isna().sum(), eliminarlos con df.dropna(), rellenarlos, quitar duplicados y crear nuevas columnas mediante fórmulas sin usar ciclos.
  
groupby sirve para dividir, aplicar y combinar datos por categorías (por ejemplo, sacar el promedio por programa).

Qué es Matplotlib?: Es una de las librerias más usada en Python para graficar.Su módulo pyplot(plt) dibuja sobre la figura paso a paso (datos, graficar, personalizar y mostrar con plt.show()).  

​Se agrega título con plt.title(), para nombres de ejes plt.xlabel() plt.ylabel(), para que al grafico le aprezca cuadricula plt.grid(True), límites plt.xlim() plt.ylim() y leyenda plt.legend() usando label en cada curva. 

El estilo de línea, color y marcador puede ir en cadena corta (ej. "r--o") o en argumentos separados (color, linestyle, marker, linewidth).
